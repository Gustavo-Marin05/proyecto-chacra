# Frontend

Este es el frontend de Chacra. Está hecho en HTML, CSS y JavaScript puros, sin dependencias. La guía de estilos está en `../design.md`.

## Demo con datos reales

`demo.html` (con `demo.js` y `demo.css`) muestra la rueda del año y la tabla mes a mes con datos de NASA POWER y MODIS. Necesita el backend encendido: ver `../backend/README.md` y abrir <http://localhost:5000/demo.html>.

Se puede enlazar un punto directamente: `demo.html?lat=-19.03&lon=-65.26`.

Las demás pantallas (`index.html`, `mi-chacra.html`, `resultado.html`, `terrenos.html` y `movil/`) siguen usando datos ilustrativos.
